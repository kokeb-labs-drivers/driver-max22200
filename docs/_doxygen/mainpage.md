# MAX22200 Driver API reference {#mainpage}

The classes, types and registers of the MAX22200 driver, generated from the headers in `inc/`.

Start with max22200::MAX22200, the driver, and max22200::SpiInterface, the base of the port you write. Errors are
max22200::Error inside max22200::Result; the configuration is max22200::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">MAX22200 Driver
documentation</a>.
