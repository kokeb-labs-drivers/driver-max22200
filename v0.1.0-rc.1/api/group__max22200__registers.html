◆ kFaultClearLsbByteFirst

constexpr bool max22200::reg::kFaultClearLsbByteFirst = true
inlineconstexpr

The SDI byte order of a selective FAULT clear (MAX22200A). true: LSB byte first, as a 32-bit write (Figure 10) and as Figure 8 draws OCP[4] in the fourth byte, so the DPM byte leads. false: MSB byte first (OCP byte first), the other reading. Not verified on hardware: the one place to change if a bench check shows the other order.
