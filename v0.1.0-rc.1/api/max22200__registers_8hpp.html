Detailed Description

MAX22200 register map: the Command Register, the 32-bit register banks, their fields, reset values and the chip's timing.

Section, table and figure names refer to the datasheet, Analog Devices 19-100531 Rev 1 (3/25).

Every access is two SPI transfers (Programming Information, "Command Register Description"): first the 8-bit Command Register, written with CMD high, which selects a bank, the direction and the length of what follows; then, with CMD low, the data: 32 bits, or only the most significant byte when bit 0 of the command is set. While the command is clocked in, SDO carries STATUS[7:0] (the Fault Flag Byte, Figure 7). Data written in 32-bit mode goes LSB byte first (Figure 10), data read comes MSB byte first (Figure 11); an 8-bit access touches bits 31:24 (Figures 12, 13).
